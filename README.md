# krugzakrugom stats

Личный инструмент автора канала «Круг за кругом» (@krugzakrugom) — короткие обзоры гонок «Формулы-1» в Instagram Reels и YouTube Shorts.

Что делает: только читает статистику собственных роликов автора (просмотры, лайки, удержание аудитории) через официальные API YouTube и Instagram и записывает её в личный журнал роликов. Ничего не публикует и не изменяет.

Это не публичный сервис: инструментом пользуется только владелец канала.
